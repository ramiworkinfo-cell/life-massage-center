# مركز الحياة للمساج — Life Massage Center

تطبيق Flutter لإدارة مركز المساج والعلاج الطبيعي، مع دعم العربية والإنجليزية والبنية المحلية Offline-first.

## المزايا الحالية
- الخدمات والعملاء والمعالجون.
- الحجوزات ومنع التعارض وساعات العمل والعطل.
- الفواتير والدفعات والعملات JOD/USD/SAR/AED.
- المستخدمون والصلاحيات وكلمات المرور المجزأة.
- التقارير ونقاط الولاء.
- WhatsApp والروابط الاجتماعية والطقس.
- النسخ الاحتياطي والاستعادة والتحقق من سلامة النسخ.

## البناء
يتوفر GitHub Actions لبناء APK وAAB. عند تشغيل workflow يتم إنشاء مجلد Android تلقائيًا ثم تشغيل التحليل والاختبارات والبناء.

راجع `RELEASE_CHECKLIST.md` قبل النشر.
